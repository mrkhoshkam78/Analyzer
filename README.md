# GodWorld V1.0

بازی شبیه‌سازی جهان دوبعدی — تو نقش خدای جهان هستی.

## ساختار (تک‌فولدر)

همه فایل‌ها کنار هم هستند:

```
GodWorld/
├── GodWorld.html      ← نسخه تک‌فایله (پیشنهادی برای اجرا)
├── index.html         ← نسخه ماژولار
├── styles.css
├── main.js
├── NPC.js
├── Tribe.js
├── Religion.js
├── MapSystem.js
├── NPCSystem.js
├── ... (بقیه سیستم‌ها)
└── README.md
```

## اجرا

### روش ۱ — ساده‌ترین (آفلاین)
فقط فایل **`GodWorld.html`** را دوبار کلیک کن.

### روش ۲ — GitHub Pages
همین فولدر را آپلود کن.  
اگر می‌خواهی نسخه ماژولار کار کند، به سرور نیاز دارد.  
برای GitHub Pages بهتر است از `GodWorld.html` استفاده کنی (اسمش را `index.html` بگذار).

### روش ۳ — توسعه
```bash
python3 -m http.server 8080
```
سپس `http://localhost:8080` را باز کن.

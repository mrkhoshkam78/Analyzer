تحلیل‌گر بازار آفلاین — نسخه ۶.۰۵ (V6.05)
==========================================
تغییرات اصلی V6.05:
- بخش مستقل «تحلیل بنیادی» از منو و UI حذف شد.
- Toggle «تحلیل فاندامنتال» داخل فرآیند Prediction اضافه شد.
- اتصال امن به EODHD فقط از طریق Backend (Token در Environment).

اجرای Backend (الزامی فقط وقتی Toggle روشن است)
-----------------------------------------------
  cd server
  export EODHD_API_TOKEN="your_token_here"
  node index.js
  # گوش می‌دهد روی http://127.0.0.1:3847

Endpoint:
  GET /api/health
  GET /api/fundamental?symbol=XAUUSD

رفتار Toggle:
  OFF → Prediction فقط تکنیکال، هیچ درخواست EODHD
  ON  → دریافت فاندامنتال از Backend → Normalize → ورودی اختیاری به موتور Prediction فعلی

داده باندل‌شده (همان V6.0):
  data/XAUUSD_1D.csv , data/BRENT_1D.csv و seedهای logic/

امنیت:
  Token فقط در process.env.EODHD_API_TOKEN روی سرور
  هرگز در Frontend / localStorage / Git قرار نمی‌گیرد

استفاده Frontend:
  1) index.html را باز کنید (یا با یک static server ساده)
  2) نماد را انتخاب کنید
  3) Toggle را روشن/خاموش کنید
  4) «اجرای تحلیل» را بزنید

تحلیل‌گر بازار — نسخه کاملاً آفلاین
====================================

بدون سرور · بدون API · بدون CMD

نحوه استفاده
------------
1) فایل index.html را در مرورگر باز کنید
   (اگر Worker خطا داد، با یک سرور استاتیک ساده مثل باز کردن از VS Code Live Server)

2) نماد را انتخاب کنید: XAUUSD / USDEUR / BRENT
3) تایم‌فریم را مشخص کنید
4) CSV کندل‌ها را بارگذاری یا بچسبانید
5) «اجرای تحلیل» را بزنید

ساختار
------
index.html / styles.css / app.js   رابط
logic/                             موتور تحلیل آفلاین

داده بازار فقط از فایل شماست. هیچ درخواست اینترنتی برای قیمت یا نماد انجام نمی‌شود.

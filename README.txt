تحلیل‌گر بازار آفلاین — V5.1
================================
تغییرات اصلی نسبت به V5.05:
- موتور فاندامنتال واقعی با ۵ متغیر: Fed Funds, CPI, NFP, DXY, US10Y
- وزن‌دهی Asset-aware برای Gold / Oil / Forex
- ورود دستی Actual / Forecast / Previous / Date + محاسبه خودکار Change/Surprise
- ذخیره‌سازی محلی ماندگار داده‌های ماکرو
- Sidebar حرفه‌ای (Dashboard / Market / Technical / Fundamental / Forecast / History / Settings)
- نمایش Technical + Fundamental + Combined Score در Forecast
- ترکیب اصولی با Technical (0.7 / 0.3 وقتی داده فاندامنتال موجود باشد)

استفاده:
1) فایل‌ها را از ZIP استخراج کنید
2) index.html را در مرورگر باز کنید
3) نماد را انتخاب کنید
4) از منوی کناری «فاندامنتال» داده‌های ماکرو را وارد و ذخیره کنید
5) داده قیمت را وارد/ایمپورت کنید و «اجرای تحلیل» بزنید

توجه: بدون داده فاندامنتال، موتور فقط تکنیکال کار می‌کند (رفتار قبلی حفظ شده).
